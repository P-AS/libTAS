# Notes for agents

## Wine

`wine.md` documents everything about running Windows games through Wine:
problems found, how they were fixed, design choices, and what is still open.

- Read it before working on anything Wine related.
- When you fix a Wine problem, make a design choice, find a limitation, or learn
  something worth knowing (including debugging techniques), add it to
  `wine.md` in the matching section, with the commit hash when there is one.
- Keep the "Open problems" section current: add what you could not solve and
  remove what you fixed.
